# Teste-de-Software
# Atividades TypeScript

Repositório contendo atividades básicas desenvolvidas em **TypeScript**, com o objetivo de praticar conceitos fundamentais da linguagem.

## 📚 Atividades

### Atividade 1 — Condicional `if/else`

Exercício utilizando uma variável do tipo `string` e uma estrutura condicional.

O programa verifica o valor da variável `pelopidasriodoce`:

* Se for `"Av. Brasil"`, exibe **"Chegaremos cedo"**.
* Caso contrário, exibe **"Andaremos muito"**.

Conceitos praticados:

* Declaração de variáveis
* Tipagem `string`
* Estrutura condicional `if/else`
* `console.log()`

---

### Atividade 2 — `type`, objeto e função

Exercício utilizando um **type** para definir a estrutura de um objeto.

Foi criado o tipo `Nara`, contendo as propriedades:

* `pos`
* `temPaciencia`
* `facul`
* `fap`
* `aws`

Depois, foi criado um objeto `perfil` seguindo essa estrutura.

A função `descreverPerfil()` recebe esse objeto e retorna uma descrição utilizando **template literals**.

Conceitos praticados:

* `type` no TypeScript
* Tipagem de objetos
* Funções
* Parâmetros tipados
* Template literals
* Interpolação de valores

---

### Atividade 3 — Estrutura de repetição `while`

Exercício que utiliza um loop `while` para gerar a tabuada do número **7**.

O programa começa com `valor2` igual a `0` e continua executando enquanto `valor2` for menor ou igual a `500`.

A cada repetição, é exibida a multiplicação:

```text
7 x 0 = 0
7 x 1 = 7
7 x 2 = 14
...
7 x 500 = 3500
```

Conceitos praticados:

* Tipo `number`
* Estrutura de repetição `while`
* Incremento com `++`
* Operações matemáticas
* Template literals

---

### Atividade 4 — Estrutura de repetição `for`

Exercício utilizando um loop `for`.

O programa executa a repetição **500 vezes**, exibindo a mensagem:

```text
Dá pontuação máxima pra gente, Breno
```

Conceitos praticados:

* Estrutura de repetição `for`
* Declaração e incremento de variável
* `console.log()`
